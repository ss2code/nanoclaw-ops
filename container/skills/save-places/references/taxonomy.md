# Place taxonomy

Assign one or more broad categories. Prefer these stable IDs; use lowercase
hyphenated tags for finer qualities such as `rooftop`, `dog-friendly`,
`reservation-needed`, `sunset`, or `quiet`.

| ID | Use for |
|---|---|
| `food-drink` | Restaurants, cafes, bars, bakeries, food markets |
| `nature-scenery` | Parks, gardens, lakes, beaches, viewpoints, wildlife |
| `hikes-walks-cycling` | Trails, urban walks, cycling routes |
| `culture-history` | Museums, heritage, architecture, monuments, spiritual sites |
| `arts-entertainment` | Galleries, theatre, cinema, music, games |
| `nightlife` | Clubs, comedy, late-night venues |
| `shopping-markets` | Markets, bookshops, boutiques, crafts |
| `sports-adventure` | Sports venues, climbing, kayaking, adventure |
| `wellness` | Spas, yoga, meditation, retreats |
| `family-children` | Child-focused and explicitly family-friendly places |
| `day-trips-drives` | Nearby excursions and scenic drives |
| `staycations` | Resorts and local overnight stays |

Rules:

- A place can have multiple categories.
- Do not create a broad category from a marketing adjective.
- Unknown category-like terms become tags, preserving information without
  expanding the stable taxonomy.
- Accessibility, price, ambience, dietary options, seasonality, booking needs,
  and suitability belong in tags or verified comments.
